# splits-distributor

splits-distributor wraps the 0xSplits contract surface: find split contracts for an address, read undistributed balances, and build distribution transactions. Use it for revenue-share automation or splits keeper tooling.

## When to use

Automating 0xSplits distributions or monitoring split balances on EVM chains.

## Install

```
cargo add splits-distributor
```
